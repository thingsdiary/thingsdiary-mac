# Лаборатория анимаций списка

Лаборатория сравнивает шесть анимаций добавления и удаления строк на макете списка thingsdiary. Один клик запускает одинаковую операцию во всех карточках, поэтому варианты легко сравнить вживую.

Запуск:

```sh
swift run --package-path DesignLab/ListAnimationLab
```

Что можно проверить:

- обычные записи, закладки, архив, корзину и темплейты;
- добавление в начало списка;
- удаление верхней строки или выбранной строки в отдельной карточке;
- длительность анимации от 120 до 600 мс;
- поведение с имитацией настройки «Уменьшение движения».

Вариант «Сверху вниз» отмечен как кандидат для приложения. Стек открывает под новую строку место, а её содержимое проявляется внутри этой области с коротким смещением в 8 пт. Маска не даёт тексту проезжать поверх соседней записи. Строка и разделитель анимируются как один элемент. При удалении движение идёт в обратную сторону.

В лаборатории используется `ScrollView` с `LazyVStack`, потому что macOS `List` частично управляется AppKit и может игнорировать пользовательские переходы строк. Перед переносом в основной интерфейс нужно отдельно проверить выделение нескольких строк, контекстные меню, drag and drop и сохранение позиции прокрутки.
